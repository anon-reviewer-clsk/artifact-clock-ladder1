# PREREG — 阶段 2（在采集之前冻结）

**冻结时间**：2026-11-20 19:1x，**在任何阶段 2 数据产生之前**

## 1 数据单元

- 独立样本 = **一次推理运行**（每 run 一行摘要），不是窗口内的采样点。
- 每模型 8 次运行，分两 session：**rounds 1–4 = A**，**rounds 5–8 = B**（同日、相隔约 10 分钟）。
  > 这是 **same-day**，不是跨日；报告中必须标注，不得称跨日迁移。
- 每轮内 4 个模型顺序随机（seed 20261120），消除模型与时间共线。

## 2 特征（只此四类，不再扩充）

| 集合 | 内容 |
|---|---|
| `PMC` | 每次运行的四 box 计数 `[box0, box1, box2, box3]`（3 s 窗口，粗粒度） |
| `SIZE` | 模型文件字节数（单一数值） |
| `RTT` | 该次运行推理 p50 延迟 |
| `LAYOUT` | 输入缓冲物理地址的高 24 位（粗粒度布局代理） |

派生：`PMC+SIZE+RTT`（全量）、`SIZE+RTT`（去掉 PMC）。

## 3 分类器与验证

- 最近质心；**标准化参数只在训练 session 上拟合**。
- `A→B`：rounds1–4 训练、5–8 测试；`B→A` 反之。每模型每 session 4 个样本。
- chance：4 类 = 0.25；near-null 对（tok_v4 vs tok_v4_l1）= 0.5。
- 置换检验：打乱**测试运行的模型标签**，B=2000，p=(1+#≥obs)/(1+B)。
- 区间：按 run 重采样 bootstrap（B=2000）。

## 4 主判据（先写死）

| 编号 | 判据 | 含义 |
|---|---|---|
| **P1** | `PMC` 单独准确率 ≤ `SIZE` 单独 | PMC 未提供超出规模的信息 |
| **P2** | `PMC+SIZE+RTT` ≤ `SIZE+RTT` | PMC 无增量价值 |
| **P3** | near-null 对 2 类准确率 ≤ 0.5 或 p > 0.05 | 同架构不同权重不可分 |
| **P4** | `LAYOUT` 单独不得显著高于 chance | 物理布局不独立泄露 |

**结论规则**：
- P1 或 P2 成立 → 结论降级为"**规模/延迟分类**"，**不是**微架构模型指纹（用户第 7 条）。
- P3 不成立（即 pair 可分）→ 才可称"权重相关信号"，且需二次独立 session 复核。
- 任一判据指向阴性 → **停止**，不调参、不增采、不换模型。

## 5 不做的

- 不做盲识别（不在未知模型集合上做开集判定）。
- 不使用阶段 1 的地址定向臂（3/6 为 0，不稳定）。
- 不把窗口内采样点当独立样本。
